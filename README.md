# CS 330 Computational Graphics and Visualization

This repository includes my final project for CS 330. For my project, I created a 3D scene using C++ and OpenGL. The scene includes a mug, book, pencil holder, pencil, and textured floor. Throughout the course, I worked on the project in different milestones by adding objects, camera movement, textures, lighting, and other features until everything came together into the final scene.

## How do I approach designing software?

Working on this project helped me understand that designing software is not always about trying to finish everything at one time. I had to look at the scene as smaller parts and figure out what needed to be completed first before moving on. I started with basic shapes and then worked on positioning, scaling, textures, lighting, and the camera controls. One design skill I improved was being able to look at a real object and decide which basic 3D shapes could be combined to make something similar. For example, I used a cylinder and torus to create the mug and used a cylinder and cone to create the pencil.

The design process I followed was mostly building something, running the program, looking at the result, and then making adjustments. There were several times when something technically worked but did not look right. I had to keep changing values until the objects were positioned correctly and looked closer to what I wanted. I can use this same approach in future projects because breaking a larger problem into smaller parts makes it easier for me to understand what needs to be fixed.

## How do I approach developing programs?

One of the biggest things I learned while developing my 3D scene was how important it is to test the program as I make changes instead of waiting until the end. I ran into different problems during the project, including my texture files not loading because of the file paths, the lighting making the floor too bright, and the pencil tip not lining up correctly with the pencil body. Instead of changing several things at once, I started making smaller changes and running the program again to see exactly what each change did.

Iteration was a major part of developing this project. Almost every part of the scene took more than one attempt before I was happy with it. The milestones helped because I was able to build on the code I already had instead of starting over each week. As the course continued, I became more comfortable working with the existing code, adding new functions, and figuring out where changes needed to be made. By the final project, I had a better understanding of how the different parts of the program worked together.

## How can computer science help me in reaching my goals?

Computational graphics and visualization gave me a different type of programming experience than some of my other computer science courses. I learned more about working with coordinates, 3D objects, textures, lighting, camera movement, and user controls. It also showed me that a program can run without errors and still need more work because the final result may not look or behave the way I intended.

I think these skills will help me in future computer science courses because I have gotten better at troubleshooting, testing changes, and working through larger projects one section at a time. Professionally, I think the experience will also be useful because software development involves more than just writing code. You have to be able to test what you create, find problems, make improvements, and continue adjusting the program until it meets the goal. This project gave me more experience doing that from the beginning of a project all the way through the finished result.
